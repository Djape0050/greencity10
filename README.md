# GREEN CITY 010 – sajt

Statičan sajt, spreman za GitHub Pages.

## Objavljivanje
1. Napravite novi repozitorijum na GitHubu i otpremite SVE fajlove iz ovog foldera (uključujući `.nojekyll` i folder `assets`) u koren repozitorijuma.
2. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save.
3. Posle 1–2 minuta sajt je dostupan na `https://<korisnik>.github.io/<repozitorijum>/`. Prvo se učitava početna stranica (`index.html`).

## Fajlovi
- `index.html` – početna stranica
- `usluga.html` – stranica pojedinačne usluge (`usluga.html?u=...`)
- `support.js`, `image-slot.js` – izvršni kod stranica
- `assets/` – logo i favicon
